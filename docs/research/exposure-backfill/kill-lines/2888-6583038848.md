### Signal pool (fixed before any return is read)
CZ's catalogue has no "slow" or rebalance-frequency category, and its `Portfolio Period` column is the original paper's holding period (it marks `dNoa`, `NOA`, `PS` as 1-month), so it cannot separate slow from fast. **Substitute rule:** pool = every `SignalDoc.csv` row with `Cat.Signal = Predictor`, `Cat.Data = Accounting` (built from annual or quarterly statements, so the signal changes at most quarterly) and `SampleEndYear <= 2005` (79 signals), **plus** the first limit's CZ desk-read signals `AssetGrowth`, `CompEquIss`, `ShareIss1Y`, `CBOperProf`, `XFIN` (only `CBOperProf`, sample end 2014, is not already in by the rule). Pool = 80. `NetEquityFinance` enters by the rule, not as a desk-read signal.

**Full series (eligibility, a presence check, not a return):** a pool signal is eligible only if its `LS` row is present and non-null in **every month 1990-01..2025-12 (432 months) in both files**. The screen file often holds quintiles or fewer ports rather than deciles; that does not matter because only `LS` is used. The script prints the eligible list.

### Selection (1990-01..2008-12 only)
The script's first query reads only `date >= 1990-01-01 AND date < 2009-01-01` from the **VW file**, and selection finishes and is printed before any later month is queried.
1. For each eligible signal: t of its monthly VW `LS` over the 228 months (t method below). CZ's `LS` is already signed so the published direction is positive; no re-signing.
2. Take the highest t. Then, in descending t (ties broken by `signalname` ascending), add each signal whose |Pearson corr| of monthly VW `LS` (same 228 months) with **every** already-selected signal is **≤ 0.30**. Stop at **8**.
3. Fewer than **4** selected → **VOID** (no evaluation cell is read).
The same selected set is used in both files; no re-selection on the screen file.

### Combine rule (one)
Composite monthly return = **equal-weight average of the selected signals' raw monthly `LS`** in that file and month. No scaling, no vol weighting, no sign flips.

### Cells (six decision cells)
2 weightings (VW file, NYSE-p20 screen file) × 3 windows **2009-01..2025-12, 2016-01..2025-12, 2020-01..2025-12** (end = the files' latest common month, 2025-12, per the structure probe). A cell is INSUFFICIENT if any selected signal is missing `LS` or has a null in any month of the cell.

### Statistics and thresholds
- Mean %/month; **t = mean / (sample sd with ddof 1 / √n)**, ordinary, no HAC, no selection adjustment (as #2828).
- A cell passes only if composite mean **≥ 0.10 %/month** and **t ≥ 1.0**. Equality passes; a strict shortfall fails. Unrounded values are compared.
- **Verdict: PASS only if all six cells pass. FAIL if any comparable cell fails. INSUFFICIENT only if no cell fails but at least one cannot be evaluated. VOID if fewer than 4 signals are selected.**

### Reported only, never changes the verdict
- Per cell: positive-month share; worst rolling 12-month compounded composite return.
- The #2828 L/S cost floors (VW 0.1748, screen 0.2436 %/month at 120% turnover per leg per year) as a comparison line; composite turnover is unknown.
- Each selected signal's own mean and t per cell, and the selected set's mean pairwise correlation in 2009+ (VW). Descriptive; none can rescue or kill.
- Max abs error of `LS` vs (top port − `01`) per selected signal, a data sanity line only.
