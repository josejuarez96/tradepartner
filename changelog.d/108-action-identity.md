### Added
- `corporate_actions.source_action_id` (`''` = none), `corporate_actions.cancelled` and the unique index `corporate_actions_identity`; `CorporateAction.source_action_id`/`cancelled`; schema version 4, with a migration from version 2 or 3 that rebuilds `corporate_actions` in one transaction and keeps every row; `tradepartner.store.asof.live_actions_as_of` (the live latest revision per action identity); fixture cases `SEC_SPLIT_REDATED`, `SEC_SPLIT_REDATED_NOID` and `SEC_DIV_CANCELLED` (#108).
### Fixed
- A corporate action re-dated by the source no longer applies twice: an action's identity is its source id when present, else `(security_id, action_type, ex_date)`; `adjusted_prices_as_of`, `dropped_dividends_as_of` and the universe/gap split factors (`universe._split_factors`, rule 8 share adjustment and gap size share) take the latest revision per identity before the ex-date and cancel filters, so a re-date past T or a cancellation retires the older revision. The fixture contract stamps a replacement row (id-less re-date, or an id-less key switching to a source id) at its ingest and refuses an id row that shares a live id-less key (#108).
